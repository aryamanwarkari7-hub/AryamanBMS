# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Contact the repository maintainer privately with:

- A clear description of the issue
- Steps to reproduce it
- Potential impact
- Suggested mitigation, if known

Do not include passwords, production connection strings, employee data, or private documents in the report.

## Supported Versions

Security fixes apply to the latest maintained version of the project.
